# Wookey 설치와 사용 안내

## 설치 파일 선택

Wookey는 macOS 14 이상을 대상으로 Apple Silicon과 Intel용으로 빌드합니다.

| 설치 파일 | 받는 곳 |
| --- | --- |
| 정식 버전 | [GitHub의 최신 정식 릴리스](https://github.com/movvgli/Wookey/releases/latest)에서 Apple 공증을 마친 DMG를 받습니다. 예전 버전의 앱과 파일은 Monkey 또는 Wikey라는 이름으로 표시될 수 있습니다. |
| 프리뷰 | [GitHub Releases](https://github.com/movvgli/Wookey/releases)에서 **Pre-release**로 표시된 Wookey DMG를 받습니다. 최신 기능을 먼저 써 볼 수 있는 Apple 공증 전 빌드로, macOS에서 실행이 제한될 수 있습니다. |

DMG를 열고 앱을 **응용 프로그램** 폴더로 옮겨 실행합니다. 프리뷰 파일 무결성을 확인하려면 같은 릴리스의 DMG와 `.sha256`을 한 폴더에 받은 뒤 터미널에서 `shasum -a 256 -c`에 받은 체크섬 파일 이름을 넘기세요.

## 첫 실행

- **⌥ Space**를 누르고 설치된 앱, 템플릿 또는 워크플로를 찾아보세요. Enter는 선택한 항목을 실행하고, **⌘ Enter**는 기본 브라우저에서 웹 검색을 엽니다. 검색 엔진과 검색창 단축키는 **설정 → 일반**에서 바꿀 수 있습니다. 기본값은 Google이며 네이버, 다음, 네이트도 선택할 수 있습니다.
- 자주 쓰는 문구는 **템플릿**에 저장합니다. **새 워크플로 → 여러 동작 연결…**에서 앱 열기, 템플릿 붙여넣기, 대기와 창 배치를 원하는 순서로 묶을 수 있습니다.
- 파일을 끌다가 두 번 흔들면 우키 서랍이 열립니다. **설정 → 일반 → 서랍 열기 감도**에서 흔들기 감도를 조절할 수 있습니다. 앱의 보관함에서 서랍과 클립보드 기록을 확인하고 **설정 → 보관 기간**에서 기록 여부와 기간을 조정합니다.
- **설정 → 일반**에서 로그인 시 실행을 설정합니다. **설정 → 테마**에서 색상 테마, 캐릭터, 아이콘 테마와 Dock·메뉴 막대 표시를 설정할 수 있습니다.

## 권한

**설정 → 권한**에서 사용하는 기능에 맞게 허용합니다. 앱이나 링크 열기와 템플릿 복사는 아래 권한 없이 사용할 수 있습니다.

| 권한 | 필요한 기능 |
| --- | --- |
| 손쉬운 사용 | 외부 앱에 자동 붙여넣기, Enter 입력, 창 이동·크기 변경, 두 단계 단축키 처리 |
| 입력 모니터링 | 두 단계 단축키의 두 번째 키 감지 |

붙여넣기와 창 배치는 대상 앱의 지원 범위에 따라 달라집니다. 앱을 교체한 뒤 권한이 적용되지 않으면 Wookey를 종료하고 다시 실행한 후 권한 상태를 확인하세요.

## 업데이트

정식 버전은 실행 중 하루에 한 번 업데이트를 확인합니다. 앱 메뉴의 **업데이트 확인…** 또는 **설정 → 업데이트**에서 직접 확인할 수 있으며, 자동 다운로드는 기본값이 꺼짐입니다. 프리뷰는 정식 업데이트 채널에 게시되지 않으므로 새 프리뷰를 쓰려면 GitHub Releases에서 직접 받으세요.

## 소스에서 실행

```sh
git clone https://github.com/movvgli/Wookey.git
cd Wookey
./script/build_and_run.sh
```

생성된 앱은 `dist/Wookey.app`에 있습니다.
